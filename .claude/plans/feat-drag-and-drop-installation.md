# Feature: Drag-and-Drop DMG Installation

## Feature Summary

Replace the plain, backgroundless DMG produced by `deploy.sh` with a professional macOS drag-to-install experience: a 660x400 Finder window with a branded dark background image, positioned app icon on the left, Applications alias on the right, and Night District visual language throughout.

## User Value

First impressions matter at install time. The current DMG mounts as a plain Finder window with no instructions, no branding, and no affordance for what to do next. A branded installer window communicates quality, matches the bar-ticket-site design language, and eliminates user confusion about how to install the app.

---

## Investigation Findings

### Current deploy.sh pipeline (single-pass, no staging)

```
hdiutil create -volname "Bar Ticket" -srcfolder "$APP" -ov -format UDZO "$DMG"
```

This uses `-srcfolder` which creates a flat compressed image directly from a folder. It does not support:
- Setting a background image
- Placing an Applications symlink
- Running AppleScript to configure the Finder window layout

The fix requires a two-pass approach: build a staging folder, create a writable R/W image from it, mount, configure with AppleScript, unmount, then convert to read-only compressed UDZO.

### Night District Branding Tokens (from bar-ticket-site)

| Token | Value |
|---|---|
| Background | `#0a0a0f` |
| Body (slightly lighter) | `#0d0d0f` |
| Primary / accent pink | `#FF00F9` |
| Primary light | `#FF80FC` |
| Primary dark | `#CC00C7` |
| Primary darker | `#9900CC` |
| Grid lines | `rgba(255,255,255,0.03)` at 60px spacing |
| Glass border | `rgba(255,255,255,0.10)` |
| Pink glow | `rgba(255,0,249,0.18)` |
| Font | Avenir, Inter, system-ui |
| Mono font | SF Mono, Fira Code |

### App Icon

The icon asset catalog lives at `/Users/loganriedley/Developer/night-district/bar-ticket/Icons/bar_ticket_icon.icon/`. When the `.app` is built and exported, Xcode compiles it to `BarTicket.app/Contents/Resources/AppIcon.icns`. The deploy script can extract a PNG from this `.icns` at runtime using `sips`, or the background image can reference the icon visually by design rather than embedding a live copy.

### No existing PNG assets in the repo

There are no pre-made PNGs in the bar-ticket repo. The background image must be **generated by a script** at deploy time, or **pre-committed** as a PNG asset. The recommended approach is a **Python + Pillow generation script** committed alongside deploy.sh, so the background can be regenerated any time the design changes without needing design tools.

### 2. Updated deploy.sh

Full replacement for `.claude/skills/deploy/deploy.sh`:

```bash
#!/bin/bash
set -e

DEPLOY_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
EXPORT_DIR="$HOME/Developer/night-district/bar-ticket/exports"
SITE_DIR="$HOME/Developer/night-district/bar-ticket-site"
BACKGROUND_SRC="$DEPLOY_DIR/dmg-background.png"

# ─── Find newest .app ───────────────────────────────────────────────────────
APP=$(ls -td "$EXPORT_DIR"/*.app 2>/dev/null | head -1)
if [ -z "$APP" ]; then
  echo "No .app found in $EXPORT_DIR"
  exit 1
fi

APP_NAME=$(basename "$APP" .app)
echo "Found: $APP_NAME.app"

# ─── Paths ──────────────────────────────────────────────────────────────────
STAGING_DIR="/tmp/bar-ticket-dmg-staging"
RW_DMG="/tmp/BarTicket-rw.dmg"
FINAL_DMG="$SITE_DIR/assets/releases/BarTicket.dmg"
VOLUME_NAME="Bar Ticket"
MOUNT_POINT="/Volumes/$VOLUME_NAME"

# ─── Clean up from any previous failed run ──────────────────────────────────
rm -rf "$STAGING_DIR"
rm -f "$RW_DMG"

# Unmount any leftover mount from previous run
if [ -d "$MOUNT_POINT" ]; then
  hdiutil detach "$MOUNT_POINT" -quiet 2>/dev/null || true
fi

# ─── Build staging folder ───────────────────────────────────────────────────
echo "Building staging folder..."
mkdir -p "$STAGING_DIR/.background"

# Copy .app
cp -R "$APP" "$STAGING_DIR/$APP_NAME.app"

# Create Applications symlink
ln -s /Applications "$STAGING_DIR/Applications"

# Copy background image into hidden .background folder
if [ ! -f "$BACKGROUND_SRC" ]; then
  echo "Background image not found at $BACKGROUND_SRC"
  echo "Run: python3 $DEPLOY_DIR/generate-background.py"
  exit 1
fi
cp "$BACKGROUND_SRC" "$STAGING_DIR/.background/background.png"

# ─── Create writable DMG from staging folder ────────────────────────────────
echo "Creating writable DMG..."
# Size: staging folder size + 20MB headroom for DS_Store writes
STAGING_SIZE_KB=$(du -sk "$STAGING_DIR" | cut -f1)
DMG_SIZE_MB=$(( (STAGING_SIZE_KB / 1024) + 20 ))

hdiutil create \
  -volname "$VOLUME_NAME" \
  -srcfolder "$STAGING_DIR" \
  -ov \
  -fs HFS+ \
  -format UDRW \
  -size "${DMG_SIZE_MB}m" \
  "$RW_DMG"

# ─── Mount the writable DMG ─────────────────────────────────────────────────
echo "Mounting writable DMG..."
hdiutil attach "$RW_DMG" -mountpoint "$MOUNT_POINT" -nobrowse -quiet

# Give Finder a moment to register the volume
sleep 2

# ─── Configure Finder window via AppleScript ────────────────────────────────
echo "Configuring Finder window layout..."
osascript <<APPLESCRIPT
tell application "Finder"
  tell disk "$VOLUME_NAME"
    open

    -- Window geometry: 660 wide x 400 tall, centered on screen
    set current view of container window to icon view
    set toolbar visible of container window to false
    set statusbar visible of container window to false
    set the bounds of container window to {400, 200, 1060, 600}

    set viewOptions to the icon view options of container window
    set arrangement of viewOptions to not arranged
    set icon size of viewOptions to 100
    set text size of viewOptions to 13
    set background picture of viewOptions to file ".background:background.png"

    -- Position app icon on the left
    set position of item "$APP_NAME.app" of container window to {165, 175}

    -- Position Applications alias on the right
    set position of item "Applications" of container window to {495, 175}

    close
    open

    update without registering applications
    delay 2
    close
  end tell
end tell
APPLESCRIPT

# ─── Flush and unmount ──────────────────────────────────────────────────────
echo "Unmounting..."
sync
hdiutil detach "$MOUNT_POINT" -quiet

# ─── Convert to compressed read-only DMG ────────────────────────────────────
echo "Converting to compressed DMG..."
hdiutil convert "$RW_DMG" \
  -format UDZO \
  -imagekey zlib-level=9 \
  -o "$FINAL_DMG"

# ─── Clean up temp files ────────────────────────────────────────────────────
rm -rf "$STAGING_DIR"
rm -f "$RW_DMG"

DMG_SIZE=$(du -sh "$FINAL_DMG" | cut -f1)
echo "Created: BarTicket.dmg ($DMG_SIZE)"

# ─── Commit and push ────────────────────────────────────────────────────────
cd "$SITE_DIR"
git add assets/releases/BarTicket.dmg
git commit -m "Update Bar Ticket .dmg

Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>"
git push
echo "Pushed to main"

echo ""
echo "Live at: https://night-district.github.io/bar-ticket-site/"
```

### 3. Background Image Generation Script

**File:** `.claude/skills/deploy/generate-background.py`

```python
#!/usr/bin/env python3
"""
Generates the Bar Ticket DMG background image.
Night District dark branding: #0a0a0f base, pink/purple accents, grid overlay.
Output: dmg-background.png (660x400 px)

Usage:
  pip3 install Pillow
  python3 generate-background.py
"""

import os
import math
from PIL import Image, ImageDraw, ImageFilter, ImageFont

OUTPUT_PATH = os.path.join(os.path.dirname(__file__), "dmg-background.png")
W, H = 660, 400

# ─── Colors ───────────────────────────────────────────────────────────────
BG          = (10, 10, 15)
GRID        = (255, 255, 255, 8)         # ~3% white
PINK        = (255, 0, 249)
PINK_LIGHT  = (255, 128, 252)
PURPLE      = (153, 0, 204)
WHITE       = (255, 255, 255)

def hex_to_rgb(h):
    h = h.lstrip('#')
    return tuple(int(h[i:i+2], 16) for i in (0, 2, 4))


def draw_glow(canvas, cx, cy, radius, color_rgb, opacity):
    """Draw a soft radial glow using a blurred filled ellipse on a temp layer."""
    glow_layer = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    gd = ImageDraw.Draw(glow_layer)
    r = color_rgb
    gd.ellipse(
        [cx - radius, cy - radius, cx + radius, cy + radius],
        fill=(r[0], r[1], r[2], int(255 * opacity))
    )
    glow_layer = glow_layer.filter(ImageFilter.GaussianBlur(radius=radius * 0.6))
    canvas.alpha_composite(glow_layer)


def draw_grid(canvas):
    gd = ImageDraw.Draw(canvas)
    step = 60
    line_color = (255, 255, 255, 8)
    for x in range(0, W, step):
        gd.line([(x, 0), (x, H)], fill=line_color, width=1)
    for y in range(0, H, step):
        gd.line([(0, y), (W, y)], fill=line_color, width=1)


def draw_corner_brackets(draw, margin=20, arm=20, stroke=2):
    """Draw 4 corner bracket decorations in pink at 40% opacity."""
    color = (255, 0, 249, 102)  # 40% opacity

    def bracket(x, y, dx, dy):
        """Draw L-shaped bracket from corner (x,y) with arms going in dx/dy direction."""
        draw.line([(x, y), (x + dx * arm, y)], fill=color, width=stroke)
        draw.line([(x, y), (x, y + dy * arm)], fill=color, width=stroke)

    bracket(margin, margin, +1, +1)           # top-left
    bracket(W - margin, margin, -1, +1)        # top-right
    bracket(margin, H - margin, +1, -1)        # bottom-left
    bracket(W - margin, H - margin, -1, -1)    # bottom-right


def draw_dashed_arrow(draw, x0, x1, y, color, opacity):
    """Draw a dashed horizontal arrow from x0 to x1 at height y."""
    dash_on = 8
    dash_off = 6
    stroke = 2
    c = (*color, int(255 * opacity))

    x = x0
    while x < x1 - 12:
        end_x = min(x + dash_on, x1 - 12)
        draw.line([(x, y), (end_x, y)], fill=c, width=stroke)
        x += dash_on + dash_off

    # Arrowhead
    ax = x1
    draw.polygon([(ax, y), (ax - 12, y - 6), (ax - 12, y + 6)], fill=c)


def get_font(name, size):
    """Try to load a system font, fall back to default."""
    font_paths = [
        f"/System/Library/Fonts/Supplemental/{name}.ttf",
        f"/System/Library/Fonts/{name}.ttf",
        f"/Library/Fonts/{name}.ttf",
    ]
    for path in font_paths:
        if os.path.exists(path):
            try:
                return ImageFont.truetype(path, size)
            except Exception:
                pass
    # Pillow built-in fallback
    try:
        return ImageFont.load_default(size=size)
    except Exception:
        return ImageFont.load_default()


def main():
    # Base canvas (RGBA for compositing)
    img = Image.new("RGBA", (W, H), (*BG, 255))

    # Grid
    draw_grid(img)

    # Glow orbs
    draw_glow(img, 580, 40, 180, PINK, 0.15)
    draw_glow(img, 80, 360, 140, PURPLE, 0.12)

    # Bottom bar tint
    bar_layer = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    bd = ImageDraw.Draw(bar_layer)
    bd.rectangle([(0, 340), (W, H)], fill=(255, 0, 249, 15))  # ~6% pink
    bd.line([(0, 340), (W, 340)], fill=(255, 0, 249, 77), width=1)  # 30% pink line
    img.alpha_composite(bar_layer)

    draw = ImageDraw.Draw(img)

    # Corner brackets
    draw_corner_brackets(draw)

    # Dashed arrow (x: 240→420, y: 175)
    draw_dashed_arrow(draw, 240, 420, 175, PINK, 0.70)

    # "drag to install" label
    mono_font = get_font("SFMono-Regular", 11)
    label = "drag to install"
    bbox = draw.textbbox((0, 0), label, font=mono_font)
    label_w = bbox[2] - bbox[0]
    draw.text((330 - label_w // 2, 200), label, fill=(*PINK_LIGHT, 204), font=mono_font)

    # App name label
    sans_font = get_font("Avenir-Heavy", 13)
    bt_label = "Bar Ticket"
    bbox = draw.textbbox((0, 0), bt_label, font=sans_font)
    draw.text((165 - (bbox[2]-bbox[0])//2, 235), bt_label, fill=(*WHITE, 230), font=sans_font)

    # Applications label
    app_label = "Applications"
    bbox = draw.textbbox((0, 0), app_label, font=sans_font)
    draw.text((495 - (bbox[2]-bbox[0])//2, 235), app_label, fill=(*WHITE, 230), font=sans_font)

    # Bottom tagline
    tagline = "> bar-ticket --watch ~/Developer"
    bbox = draw.textbbox((0, 0), tagline, font=mono_font)
    draw.text((330 - (bbox[2]-bbox[0])//2, 362), tagline, fill=(*PINK_LIGHT, 191), font=mono_font)

    # Convert to RGB for PNG output (no alpha needed as final PNG)
    final = img.convert("RGB")
    final.save(OUTPUT_PATH, "PNG", optimize=True)
    print(f"Saved: {OUTPUT_PATH} ({W}x{H})")


if __name__ == "__main__":
    main()
```

### 4. AppleScript Deep Dive

The osascript block in deploy.sh is the most fragile part of this workflow. Key notes:

**Window bounds format:** `{left, top, right, bottom}` in screen coordinates. `{400, 200, 1060, 600}` = 660px wide, 400px tall, offset from top-left of screen — centered on a typical 1440x900 display.

**Icon positions:** Finder's `set position of item` uses the item's center point relative to the container window's canvas (not screen). With window at 660x400:
- App icon center: `{165, 175}` — left third
- Applications alias center: `{495, 175}` — right third

**Background picture path:** `file ".background:background.png"` uses the colon-separated HFS path syntax Finder expects — `.background` is the hidden folder name, `background.png` is the file. The leading `.` makes it invisible in Finder views.

**`update without registering applications`:** Required to flush the `.DS_Store` write before unmounting; without this the window layout may not persist.

**`close` / `open` cycle:** Required because the background is not applied until after the window is opened. The second `open` after setting properties forces Finder to apply them.

**Icon size 100px:** Balances visibility on a 660x400 canvas. macOS standard DMG installers use 96–128px.

## Dependencies & Risks

**Pillow (Python package)**
- Required only at background generation time, not at deploy time (PNG is pre-committed)
- `pip3 install Pillow` or `pip3 install --user Pillow`
- System Python3 is available on macOS 14+

**AppleScript / Finder interaction is fragile**
- Finder must be running (it always is on macOS)
- The `open` → configure → `close` → `open` → `close` pattern is standard but may require tuning the `delay 2` if layout doesn't persist
- If the volume name contains special characters, the AppleScript string reference will break — "Bar Ticket" with a space is safe since we quote it
- Test with `set` before `get` if positions are not persisting: some macOS versions require the window to be frontmost

**HFS+ format requirement**
- The `-fs HFS+` flag in the writable DMG creation is required for AppleScript-settable `.DS_Store` background support
- APFS DMG volumes do not support custom Finder window backgrounds — this is a known Apple limitation

**Volume name collision**
- If `/Volumes/Bar Ticket` is already mounted from a previous failed run, `hdiutil attach` will fail
- The cleanup block at the top of the script handles this with `hdiutil detach ... 2>/dev/null || true`

**`.DS_Store` not persisting after convert**
- The `update without registering applications` + `delay 2` + `close` sequence before unmounting is critical
- If the layout does not survive `hdiutil convert`, add a longer `sleep 5` before detach

**Icon label positioning**
- The text labels ("Bar Ticket", "Applications") in the background image are decorative guidelines
- Finder renders its own icon labels below the icons at the same x position as the icon center
- The background text may overlap Finder's native labels — if this looks bad, remove the label text from the PNG and rely solely on Finder's rendering. Adjust the y-position of icon labels in the background to sit slightly above the icon rather than below.
